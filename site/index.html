The FIX session layer, as a Rust library.

Codec, sessions, storage, and TCP and TLS acceptors and initiators, with typed messages for FIX 4.0 to 5.0 SP2 generated from the official FIX data. SBE and FIXP for binary order entry, and FAST for market data.

Pre-1.0, not yet proven in production. Turbojet is tested against QuickFIX/J and QuickFIX/n and fuzzed, but it hasn't been certified with any venue or run against a real counterparty, and its APIs will change before 1.0. Test it thoroughly yourself before trading real money with it. It is provided as is, without warranty of any kind.

Built for systems that can't lose a fill

Safety first, then performance, then developer experience: a bug in a FIX engine can send a duplicate order or lose a fill.

Safe

What a counterparty sends is bounded, invariants are asserted, and delivery to your application is at least once.

Deterministically simulated

Both ends run against each other from a seed, through crashes, store failures, power loss and a hostile network.

Fast

Outbound messages batched into one buffer, group commits, and allocations counted by stage on every test run.

Embeddable

A library, not a server: every layer is public, from the codec through the sans-IO session to the transports.

Interoperable

Tested in CI against QuickFIX/J and QuickFIX/n in both roles, over a proxy that loses, garbles and delays messages.

Pure Rust

No bindings to a C++ or Java engine, and no unsafe code in the engine.

The crates

Take the engine alone, or the pieces around it.

turbojet

The engine: codec, sessions, stores, transports, SBE, FIXP and (feature fast) FAST.

 turbojet-fix

Every FIX 4.0 to 5.0 SP2 application message, group and enum, a feature per version.

 turbojet-config

An acceptor and initiators from a TOML file, reloaded while running.

 turbojet-sql

Session storage in SQLite or PostgreSQL, with leases between gateways.

 turbojet-replica

A hot standby that takes sessions over with no sequence gap and no resend storm.

 turbojet-codegen

Typed messages from FIX Orchestra or QuickFIX dictionaries, and SBE codecs from schemas.
