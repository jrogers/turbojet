# turbojet-fix43

FIX 4.3 application messages for [Turbojet](https://github.com/jrogers/turbojet): an enum per
enumerated field, a struct per message and repeating-group entry, and a tag constant per field
(in `tags`). Session-level messages are in `turbojet::admin`.

```rust
use turbojet::{FixMessage, FixMessageRef};
use turbojet::fields::{FromFix, UtcTimestamp};
use turbojet_fix43::{HandlInst, NewOrderSingle, NewOrderSingleRef, OrdType, Parties, Side};

let now = UtcTimestamp::from_fix("20260928-12:00:00.000").unwrap();
let mut order = NewOrderSingle::new("ORD1", HandlInst::AutomatedExecutionNoIntervention, Side::Buy, now, OrdType::Market);
order.symbol = Some("AAPL".into());
order.party_ids.push(Parties::new("FIRM"));
let msg = order.to_message();
let parsed: NewOrderSingle = msg.parse().unwrap();
assert_eq!(parsed, order);
let borrowed: NewOrderSingleRef = msg.parse().unwrap();
assert_eq!(borrowed.into_owned(), order);
```

Each message and group also has a borrowed form, such as `NewOrderSingleRef`, whose strings and
groups borrow from the received message rather than copying it: read messages with it, and call
`into_owned()` to keep one.

FIX 4.3 components such as Instrument and OrderQtyData are flattened into the messages that use
them (`order.symbol`, `order.order_qty`); repeating groups, Parties among them, are structs with
their official names.

Enumerated fields are typed `turbojet::fields::Code<E>`: a code the dictionary lists is
`Code::Known`, and any other is kept as `Code::Unknown` rather than failing the parse, as in
QuickFIX, so a venue's own value in a field the application never reads doesn't cost the message.
Compare a field with a value directly (`order.side == Side::Buy`), and set one with `.into()`. To
reject unknown codes, check messages against a data dictionary (`SessionConfig::with_dictionary`,
feature `validation`), which answers them with a Reject, or generate your own messages with
`--strict-enums`. To name a venue's extra values, merge its dictionary and generate your own
(`turbojet-codegen OrchestraFIX43.xml --merge venue.xml`, or `Dictionary::merge_file` in a `build.rs`).

The code is generated by `turbojet-codegen` from `dictionaries/orchestra/OrchestraFIX43.xml`,
which is converted from the FIX Trading Community's FIX Unified Repository (2010 Edition), since
FIX 4.3 isn't among their published Orchestra files; groups and enum values have their official
names. Each item's docs give its FIX name and tag. Don't edit `src/generated`, run
`scripts/codegen.sh`.
