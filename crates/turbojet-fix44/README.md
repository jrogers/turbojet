# turbojet-fix44

FIX 4.4 application messages for [Turbojet](https://github.com/jrogers/turbojet): an enum per
enumerated field, a struct per message and repeating-group entry, and a tag constant per field
(in `tags`). Session-level messages are in `turbojet::admin`.

```rust
use turbojet::{FixMessage, FixMessageRef};
use turbojet::fields::{FromFix, UtcTimestamp};
use turbojet_fix44::{NewOrderSingle, NewOrderSingleRef, OrdType, Parties, PartyRole, Side};

let now = UtcTimestamp::from_fix("20260928-12:00:00.000").unwrap();
let mut order = NewOrderSingle::new("ORD1", Side::Buy, now, OrdType::Market);
order.symbol = Some("AAPL".into());
let mut firm = Parties::new("FIRM");
firm.party_role = Some(PartyRole::ExecutingFirm);
order.party_ids.push(firm);
let msg = order.to_message();
let parsed: NewOrderSingle = msg.parse().unwrap();
assert_eq!(parsed, order);
let borrowed: NewOrderSingleRef = msg.parse().unwrap();
assert_eq!(borrowed.into_owned(), order);
```

Each message and group also has a borrowed form, such as `NewOrderSingleRef`, whose strings and
groups borrow from the received message rather than copying it: read messages with it, and call
`into_owned()` to keep one.

FIX 4.4 components such as Instrument and OrderQtyData are flattened into the messages that use
them (`order.symbol`, `order.order_qty`); repeating groups, Parties among them, are structs with
their official names.

Enumerated fields are strict: a code the dictionary doesn't list makes `parse` fail with an
incorrect-value error for that tag. To accept a venue's extra values, merge its dictionary and
generate your own messages (`turbojet-codegen OrchestraFIX44.xml --merge venue.xml`, or
`Dictionary::merge_file` in a `build.rs`). To accept any value, generate your own with
`--lenient-enums`, which types enumerated fields as `turbojet::fields::Code<E>` and keeps unknown
codes; or read the field from the raw `Message`.

The code is generated by `turbojet-codegen` from the official FIX Orchestra file for FIX 4.4
(Extension Pack 311, `dictionaries/orchestra/OrchestraFIX44.xml`), so groups and enum values have
their official names. Each item's docs give its FIX name and tag; for the specification's
descriptions, see [Orchimate](https://orchimate.org/fixtrading/fix-4.4) (formerly FIXimate).
Don't edit `src/generated`, run `scripts/codegen.sh`.
